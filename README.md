# Ngăn Sách Trống · Bảng Đen Số

Sản phẩm trình bày về tình trạng **thiếu sách giáo khoa năm học 2026–2027** và đề xuất cá nhân **Bảng Đen Số** – website dùng AI biến bài học trong SGK thành tài liệu rời (phiếu học tập đục lỗ).

## Chạy thử

| | Link |
|---|---|
| Tủ sách **Ngăn Sách Trống** (đầy đủ, có cả Bảng Đen Số, **AI hoạt động**) | https://claude.ai/artifact/Rj1TXW3m2QP6aCcWysNe5i |
| Bản trên GitHub Pages | https://lenguyenhongtai2602-dotcom.github.io/ngan-sach-trong/ |
| Bảng Đen Số (trang riêng, GitHub Pages) | https://lenguyenhongtai2602-dotcom.github.io/ngan-sach-trong/bang-den-so.html |

**Cách dùng:** mở link → bấm vào các cuốn sách để xem nội dung; giấy note *Infographic* và *Poster*; băng cassette là video giới thiệu ý tưởng; chiếc TV là video hướng dẫn; nút **“Dùng thử Bảng Đen Số”** trong cuốn sách tím để dùng web tạo tài liệu.

> **Lưu ý về AI:** phần tạo phiếu, lấy danh sách bài, “Cải thiện một phần” và chấm tự luận dùng AI Claude, nên chỉ hoạt động trong link **claude.ai** (người dùng cần đăng nhập tài khoản Claude; lượt dùng tính vào tài khoản của họ). Trên GitHub Pages mọi phần khác chạy đầy đủ và vẫn làm thử được phiếu mẫu, kiểm tra bài, xem đáp án.

## Công nghệ

HTML, CSS, JavaScript thuần (không cần cài đặt hay build). Thư viện tải khi cần: `pdf.js`, `mammoth` (đọc PDF/Word tải lên), `docx` (xuất file Word). AI: Claude (qua môi trường artifact của claude.ai).
